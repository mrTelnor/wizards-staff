# Посох мага (wizards-staff)

Реквизит для настольных ролевых игр: посох с полым шаром наверху, цветным экраном и кольцом светодиодов внутри. На рукояти предусмотрены 16 кнопок: восемь костей (по умолчанию d2, d4, d6, d8, d10, d12, d20, d100), четыре служебные и четыре для меню. Электроника уже работает на макетке; корпус ещё предстоит изготовить.

Игрок нажимает кнопку кости, бьёт посохом об пол, в шаре мельтешат числа, вспыхивает подсветка, и на экране остаётся результат броска. Несколько нажатий одной кнопки дают бросок нескольких костей: три раза d6, удар, на экране «3d6: 11» и слагаемые.

Проект делается так, чтобы его мог повторить любой желающий с паяльником и Arduino IDE: готовые модули, минимум пайки, весь код с комментариями, документация простым языком.

## Как это устроено

- **Мозг:** плата ESP32-C3 SuperMini, программируется в Arduino IDE.
- **Экран:** 1,54" IPS 240×240 на ST7789; в готовом посохе будет внутри полого шара из эпоксидки.
- **Подсветка:** кольцо из 12 адресных светодиодов WS2812B под экраном.
- **Кнопки:** 16 тактовых кнопок через два расширителя портов PCF8574 по шине I2C.
- **Удар:** датчик вибрации SW-420.
- **Часы:** модуль DS3231, в покое посох показывает время и заряд.
- **Звук:** электромагнитная пищалка через транзистор.
- **Питание:** аккумулятор 18650 с защитой, зарядка TP4056 через USB-C, повышающий преобразователь MT3608 до 5 В, тумблер.
- **Связь:** Bluetooth Low Energy, сервис Nordic UART и обмен JSON-сообщениями; приложение для Android без сервисов Google.
- **Корпус, в плане:** ПВХ-труба 25 мм, рукоять и оправа из ПВХ без 3D-печати, полый шар 120 мм.

Подробности, диаграмма состояний прошивки и все принятые решения в [SPEC.md](SPEC.md).

## Что уже работает

### Посох

- Броски от кнопок и удара, до десяти костей за раз; назначение восьми кнопок можно менять по BLE, грани — от d2 до d1000.
- Русские надписи на экране: часы, взвод, анимация и результат броска. Экран засыпает без действий, взвод сохраняется до броска или сброса. Неподтверждённое планшетом время отмечается на экране.
- «Сброс», «Повтор», «Свет», «Тихо». Долгий «Повтор» переключает удачу и неудачу: две попытки одной d20 с выбором лучшего или худшего результата.
- Вспышки и звуки бросков, огненное свечение с пятью палитрами. Сон экрана не гасит свечение.
- Меню на «ОК»: яркость, громкость, возврат к часам, сон экрана, тест d20 и сведения о посохе. Настройки сохраняются во флеш.
- История на 1500 бросков во флеш с номерами, переживающими перезапуск. Кнопками ◄ ► можно просмотреть последние 20 бросков, приложение догружает историю порциями.
- Передача заряда и журнала на планшет, синхронизация часов. Вход по четырёхзначному PIN, ограничение попыток и смена PIN из приложения. При незаданном PIN посох работает без защиты; PIN приложения не шифрует BLE-канал.

### Приложение

Kotlin, Jetpack Compose и Room, Android 10 и новее (minSdk 29). Основное устройство для проверки — HUAWEI MatePad SE 11 с HarmonyOS 2.0, без сервисов Google.

- Поиск и подключение посоха, вход по PIN, заряд и синхронизация времени.
- Лента бросков в базе Room: догрузка пропущенного, исключение повторов, подписи и пометки «не засчитан». Удача и неудача показывают обе попытки с зачёркнутой отброшенной.
- Журнал обмена с фильтрами, поиском, отправкой команд и сохранением в файл.
- Лист персонажа Pathfinder 2e: обзор, навыки, черты и справочник из 256 черт. Можно менять часть данных листа и создавать сохранения персонажа. Восстановление из сохранения и вкладка «Магия» ещё не реализованы.

## Как повторить

1. Купить компоненты по [hardware/bom.md](hardware/bom.md).
2. Поставить Arduino IDE и библиотеки по [firmware/README.md](firmware/README.md). Для защиты связи создать локальный `secrets.h` по [secrets.example.h](firmware/wizards_staff/secrets.example.h), затем залить прошивку из [firmware/wizards_staff/](firmware/wizards_staff/).
3. Собрать схему на макетной плате по [hardware/wiring.md](hardware/wiring.md), проверить каждый модуль.
4. При необходимости открыть папку `app/` в Android Studio, собрать и установить приложение. Основные броски работают и без планшета.
5. Перед игрой выключить «Тест d20» в меню: сейчас он включён по умолчанию для проверки эффектов и подменяет каждый второй бросок 1d20 на 20 или 1. Для новых установок значение по умолчанию задаётся `TEST_D20_CYCLE` в `config.h`.

При заливке прошивки по USB тумблер питания от аккумулятора должен быть выключен: у платы нет развязки двух источников питания. Корпус и пайка начисто — следующие этапы проекта, законченной инструкции для них пока нет.

Порядок работы и типичные проблемы по ходу сборки записаны в [JOURNAL.md](JOURNAL.md).

## Состояние проекта

На 30 октября 2026 года электроника собрана и проверена на макетке. В репозитории — прошивка 0.20.0 с меню и русским экраном, приложение с историей бросков и частично реализованным листом персонажа. Подробные проверки железа описаны в журнале за 27–29 октября; более поздние изменения видны в истории коммитов.

Впереди: корпус и пайка начисто, замер автономности готового устройства, восстановление сохранений и дальнейшая работа над листом персонажа, действия с модификаторами, полный экран настроек посоха, статистика и экспорт бросков, таймер хода и обновление прошивки по BLE. Поддержка листов D&D запланирована; сейчас правила листа реализованы для Pathfinder 2e.
