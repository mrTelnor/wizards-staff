# Прошивка: среда разработки

Скетч лежит в папке `wizards_staff/`. Имя папки совпадает с именем файла `wizards_staff.ino`, так требует Arduino IDE. Все номера ножек, адреса и тайминги собраны в `config.h`, в остальном коде номеров нет.

## Что установить

1. **Arduino IDE 2.x** с [arduino.cc](https://www.arduino.cc/en/software). На Windows можно через winget:

   ```powershell
   winget install --id ArduinoSA.IDE.stable --exact --accept-package-agreements --accept-source-agreements
   ```

2. **Пакет плат ESP32.** File → Preferences → Additional boards manager URLs, вставить:

   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

   Затем Boards Manager (вторая иконка слева), поиск `esp32`, установить «esp32 by Espressif Systems» версии 3.x.

3. **Библиотеки.** Library Manager (третья иконка слева), по очереди установить, на вопрос о зависимостях отвечать «Install all»:
   - Adafruit GFX Library
   - Adafruit ST7735 and ST7789 Library
   - Adafruit NeoPixel
   - Adafruit PCF8574
   - RTClib
   - NimBLE-Arduino (h2zero), связь с телефоном по Bluetooth, проверено на 2.5.1
   - ArduinoJson (Benoit Blanchon), обмен сообщениями с телефоном, проверено на 7.4.3

## Настройки платы

Плата ESP32-C3 SuperMini подключается кабелем USB-C с передачей данных, а не «только зарядка».

- Tools → Board → esp32 → **ESP32C3 Dev Module**
- Tools → Port → появившийся COM-порт
- Tools → **USB CDC On Boot → Enabled**, иначе Serial-монитор молчит. Этот пункт слетает в Disabled при перевыборе платы или порта, проверять, если монитор пуст
- Tools → **Partition Scheme → Minimal SPIFFS (1.9MB APP with OTA)/190KB SPIFFS**: прошивка с Bluetooth не помещается в стандартный раздел. Надпись «190KB SPIFFS» в меню неточна: под файлы на самом деле отводится 128 КБ, свободно из них 120 КБ. Замерено на плате, история бросков рассчитана по факту

Если порт не появился: зажать на плате кнопку BOOT, не отпуская подключить USB, отпустить. Плата войдёт в режим загрузчика. После заливки нажать RESET.

## Заливка

File → Open → `firmware/wizards_staff/wizards_staff.ino`, затем кнопка Upload. В конце лога «Hard resetting via RTS pin» или «Done uploading». Serial Monitor на скорости 115200.

При заливке от USB тумблер питания посоха должен быть выключен: у SuperMini нет диода между USB и ножкой 5V, кормить плату с двух сторон одновременно нельзя.

## История бросков во флеш (с 0.22.0)

**После 0.22.0 не заливать прошивку ниже 0.22.** Файл истории при первом старте 0.22.0 переводится на формат 2 (у каждой записи контрольная сумма). Прошивка 0.21 и старше этот формат не знает и создаст файл заново, то есть сотрёт историю на посохе. Перед первой заливкой 0.22.0 выгрузи историю на планшет: подключись и дождись в логах «догружено бросков с посоха». Первый старт с переводом идёт на несколько секунд дольше, в это время посох не выключать.

При заливке держать Tools → **Erase All Flash Before Sketch Upload: Disabled**: иначе стирается вся флеш, вместе с историей, PIN и номером посоха.

Раздел под файлы посох форматирует сам только при первом запуске: в NVS нет отметки, что раздел уже работал, номер последнего броска ноль, и раздел чистый. Так бывает на новой плате с чистой флеш и после Erase All Flash. Во всех остальных случаях (раздел не смонтировался, хотя работал; сменили схему разделов; на новой плате осталась чужая прошивка) посох не форматирует, а работает без истории во флеш: броски идут и уходят на планшет, в журнале ERROR, в ответе `info` поле `histok: false`. Стереть раздел осознанно — команда с планшета (экран логов):

```
{"cmd":"fsformat","confirm":"erase"}
```

Команда стирает раздел целиком, вместе со всей историей на посохе, поэтому перед ней выгрузи историю на планшет (подключись и дождись «догружено бросков с посоха»). Работает она в двух случаях: раздел не монтируется, или раздел работает, но история выключена из-за непригодного файла (см. ниже). При работающей истории и в проверочных сборках команда отказывает. Номера бросков после неё продолжаются.

Если раздел работает, а сам файл истории не читается (не тот размер, чужая шапка, незнакомая версия), посох пробует отложить его как `/rolls.old1` и завести новый. Рядом с файлом полного размера (54 КБ) на разделе 128 КБ места почти никогда нет, поэтому обычно история просто выключается, а файл остаётся нетронутым. Достать его сейчас нечем: скетча для выгрузки файла нет. Если файл нужен — сообщи автору проекта, файл подождёт. Если не нужен — выгрузи историю на планшет и сотри раздел командой `fsformat` выше.

На чистой плате в мониторе порта при первом старте бывают строки вида `nvs_open failed: NOT_FOUND` и `esp_littlefs: mount failed (-84)` — это норма: настроек и файловой системы ещё нет, посох их заведёт.

## Файлы скетча

Каждый файл делает одно дело. Номера ножек, адреса и тайминги — только в `config.h`.

| Файл | Что делает |
|---|---|
| `wizards_staff.ino` | главный цикл, разбор команд с планшета, машина состояний |
| `config.h` | ножки, адреса I2C, тайминги, кости по умолчанию, версия прошивки |
| `log.h` | единый журнал служебных сообщений: время, модуль, уровень, текст |
| `dice.h` | бросок костей, таблица костей по кнопкам, самопроверка генератора |
| `flashfs.h` | раздел под файлы LittleFS: форматирование только при первом запуске, при сбое без форматирования; команда `fsformat` |
| `history.h` | история бросков во флеш: кольцевой файл на 1500 записей, сквозные номера, контрольная сумма и проверка каждой записи |
| `identity.h` | постоянный номер посоха `staffId` |
| `ble.h` | связь с планшетом: сервис Nordic UART, заряд, очередь команд |
| `strike.h` | датчик удара SW-420 с фильтром силы удара |
| `rtc.h` | часы DS3231, отметка «время подтверждено планшетом» |
| `battery.h` | замер заряда через делитель |
| `auth.h` | PIN и защита подключения |
| `buttons.h` | 16 кнопок через два PCF8574: кости, служебные и меню; дребезг, короткое и долгое нажатие |
| `display.h` | экраны: часы, взвод, барабан и результат, история; строка состояния, яркость подсветки |
| `lights.h` | кольцо WS2812B: гасится при старте, огненная вспышка при включении, вспышки при итоге броска, свечение кнопки «Свет» |
| `sound.h` | пищалка: писк включения, тик барабана, «пуньк» итога, фанфары на 20 и 1; «Тихо» и громкость |
| `settings.h` | настройки из меню: яркость, громкость, возврат к часам, сон, тестовый режим d20; хранение во флеш |
| `menu.h` | меню на кнопке «ОК»: экран, правка значений, «Сведения» |

## Инструменты

Папка `tools/` содержит отдельные скетчи-помощники, каждый в своей папке. Они не входят в прошивку посоха.

| Скетч | Что делает |
|---|---|
| `tools/battery_log/` | пишет напряжение аккумулятора раз в 30 с в файл во флеш платы (LittleFS), читается командой `dump` в Serial Monitor. Для замера автономности без компьютера |
